# 定义、符号与共享引理

本主题默认研究有限无自环、无重弧的简单有向图。允许双向边，除非明确要求定向图。源点入度为零，汇点出度为零。以 $N^+(v)$、$N^-(v)$ 分别表示出邻和入邻集，$N^+[v]$ 含 $v$。$N^+(U)$ 是集合中各点的出邻集之并。$\Delta^+$ 是最大出度。

准核 $Q$ 是独立集，从 $Q$ 沿出弧至多走两步可达全图，含零步。小准核要求 $2|Q|\le |V|$，半数界问题假定无源。核完美与一步覆盖使用同一出向约定。[出度四证明](../proofs/匹配降度与出度四的小准核.md)

[弧细分笔记](../history/细分一条弧.md) 以及 [定义检查器](../experiments/shared/check.mjs) 的底层接口使用走向集合的约定。反转所有弧把无源、最大出度转换为无汇、最大入度。调用检查器前核对是否需要转置。
