# 统一极大局部定理（图类 $\mathcal{H}$）、定向 $(4,3)$ 紧反例与无界出度 $\alpha^+ \le k$ 推进

沿用[Clow 5.1 与一般有向图小准核证明](Clow-5.1-证明.md)及[禁出星图与 $(\Delta^+, \alpha^+)$ 相图](Clow-禁出星图与相图.md)的记号。设 $D$ 是非空有限无源简单有向图（无自环、无重弧，除非特别声明均**允许双向边**）。记非汇点集（核心）为 $C = \{v \in V(D) : d^+(v) \ge 1\}$，汇点集为 $K = V(D) \setminus C$；对 $u \in V(D)$ 记 $\alpha(u) := \alpha\bigl(D[N^+(u)]\bigr)$ 为其出邻集导出子图的最大独立集大小（独立集内任意两点双向均无弧），$\alpha^+(D) := \max_{u \in V(D)} \alpha(u)$。对 $v \in C$，仍记 $A(v) = N^+(v)$，$A_C(v) = A(v) \cap C$，$c(v) = |A_C(v)|$，$k(v) = |A(v) \cap K|$，$S(v) = R(D - N^+[v])$，$E(v) = A(v) \cup N^+(S(v))$，$g(v) = |E(v)| - |S(v)|$，$g^+(v) = g(v) + \mathbf{1}[v \in N^+(S(v))]$，以及无约束下界
$$L^*(v) = \min_{F \subseteq S(v)} \bigl(|A(v) \cup N^+(F)| - |F|\bigr).$$

本笔记完成[上一轮交接清单](Clow-禁出星图与相图.md)中的**优先级 1** 与**优先级 3**，并对**优先级 2** 给出新的通用上界、$M = 1$ 反例修正与两条新归纳约简引理：
1. **合龙统一极大局部定理（优先级 1，正面完结）**：定义逐点遗传图类
   $$\mathcal{H} := \Bigl\{ D : \forall u \in V(D),\; \alpha(u) \le 1 \;\text{ 或 }\; d^+(u) + \alpha(u) \le 6 \Bigr\}.$$
   证明每张非空有限无源的 $D \in \mathcal{H}$（允许双向边且 $\alpha(u) = 1$ 顶点出度无界）均存在 $v \in C$ 满足 $L^*(v) \ge 1$，从而推出全体 $D \in \mathcal{H}$ 均满足小准核猜想 $2|Q| \le |V(D)|$ 且多项式时间可构造。这同时统一并严格涵盖全体 $\Delta^+ \le 3$ 一般有向图、全体局部出半完全有向图（$\alpha^+ \le 1$）、全体 $(\Delta^+ \le 4, \alpha^+ \le 2)$ 禁出爪一般有向图及其任意混合图。
2. **彻底否定定向 $(4,3)$ 的 $g^+ \ge 1$ 猜想（优先级 3，负面完结）**：先证明任意 2-出正则、局部出半完全（$\alpha^+ \le 1$）定向核心必含核心新源；据此构造两层定向族 $T_5 + C_m + 10$ 私有汇点（$\Delta^+ = 4, \alpha^+ = 3$，即定向 $\vec{K}_{1,4}$-free）：
   * $m = 3$（**18 点**）：全图 $g(v) = 0$（比 Clow 的 24 点 $\Delta^+ = 4$ 反例少 6 点，且额外满足 $\vec{K}_{1,4}$-free）；
   * $m = 4$（**19 点**）与 $m = 5$（**20 点**，$\mathbb{Z}_5$ 对称）：全图 $g(v) = g^+(v) = L^*(v) = 0$；
   * 另有显式 **22 点**定向 $(4,3)$ 图使 4 个核心点严格满足 $g = g^+ = -1$、其余为 $0$。
   由此确立 $\mathcal{H}$ 的阈值 $d^+(u) + \alpha(u) \le 6$ 即使限制在**定向图**的 $g(v) \ge 1$ 与 $g^+(v) \ge 1$ 上也在 $(4,3)$ 处完全紧致。
3. **无界出度 $\alpha^+(D) \le k$ 的推进与相图修正（优先级 2）**：
   * 给出 3 行全局双计数证明：对任意 $d \ge 2$ 及任意允许双向边的无源图 $\alpha^+(D) \le d - 1$，**任意独立集 $I$（从而任意准核 $Q$）均满足 $|I| \le \frac{d-1}{d}|V(D)|$**，对所有 $d \ge 2$ 严格改进 Clow 的 $\frac{d^2-2d+2}{d^2-d+1}n$ 上界；
   * 构造无界出度 $\alpha^+(D) = 2$ 且 **$M = 1$** 的新反例族 $K_{2r}^* + 2r$ 私有汇点 $+ r$ 配对点（$5r$ 点，$r = 4, 5, 6$ 时分别在 20/25/30 点上给出全图 $g \le 0$、$g^+ \le 0$、$g^+ \le -1$），修正此前“$M = 2$ 是 $\alpha^+ \le 2$ 唯一阻碍”的判断；
   * 给出保留强预覆盖归纳 $\mathcal{P}(H, P)$ 的**引理 B（双生入度 1 子点约简）**与**引理 C（两步吸收约简）**，其中引理 B 直接消解此前引理 A 不可约的 24 点 $CP_8^* + 16$ 叶图。

## 1　统一极大局部定理（图类 $\mathcal{H}$）

注意对任意 $u \in C$，$D \in \mathcal{H}$ 等价于 $u$ 必属以下三类之一：
* **I 型**：$\alpha(u) = 1$（出度 $d^+(u) \ge 1$ 任意无界）；
* **II 型**：$\alpha(u) = 2$ 且 $d^+(u) \in \{2, 3, 4\}$；
* **III 型**：$\alpha(u) = 3$ 且 $d^+(u) = 3$。

特别地，若 $\alpha(u) \ge 2$，必有 $d^+(u) \le 4$；若 $d^+(u) \ge 5$，必有 $\alpha(u) = 1$；且全图恒有 $\alpha^+(D) \le 3$。对诱导子图 $H \subseteq D$，每个顶点 $u \in V(H)$ 同时满足 $d_H^+(u) \le d_D^+(u)$ 与 $\alpha(H[N_H^+(u)]) \le \alpha(D[N_D^+(u)])$，故 $\mathcal{H}$ 对取诱导子图**严格遗传**。

**定理 1（$\mathcal{H}$ 上的强 Clow 局部不等式）.** 对任意非空有限无源简单有向图 $D \in \mathcal{H}$（允许双向边），必存在 $v \in C$ 满足 $L^*(v) \ge 1$（从而 $L(v) \ge 1$ 且 $g(v) \ge 1$）。

**定理 2（$\mathcal{H}$ 满足小准核猜想）.** 任意有限无源简单有向图 $D \in \mathcal{H}$（允许双向边）均含独立集 $Q$ 满足 $2|Q| \le |V(D)|$ 且全图从 $Q$ 至多两步可达，且 $Q$ 可在多项式时间内构造。

*定理 2 的证明.* 因 $\mathcal{H}$ 对取诱导子图严格遗传，且定理 1 对任意非空无源诱导子图 $H \in \mathcal{H}$ 均给出 $g_H(v) \ge L^*_H(v) \ge 1$，直接沿用[Clow-5.1-证明](Clow-5.1-证明.md)中带预覆盖集 $P$（$R(H) \subseteq P$）的强归纳命题 $\mathcal{P}(H, P)$ 即得定理 2。$\blacksquare$
