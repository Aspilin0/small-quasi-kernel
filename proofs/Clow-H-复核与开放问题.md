## 4　独立复核与下一阶段开放问题

### 4.1　独立复核入口

在仓库根目录运行：

```powershell
node experiments/clow-classH-verify.mjs
```

[独立验证程序](../experiments/clow-classH-verify.mjs)将图类检查、精确 $L^*$ 暴力枚举、按定理 1 证明分支构造的局部选点器 `selectWitnessClassH`、以及基于[独立准核定义检查器](../experiments/shared/check.mjs)（转置图）的准核核验完全解耦，检验：
1. **小图穷举**：全部 3–5 点无源定向 $\mathcal{H}$ 图（16,292 张）、全部 5 点定向核心轨道（76 个）加任意 0/1 共享或私有汇点的 $\mathcal{H}$ 图（13,435 张，其中 3,289 张含 $d^+ = 4$ 点）、以及全部 4 点一般双向核心轨道（90 个）加任意 0/1 汇点的 $\mathcal{H}$ 图（4,018 张，其中 1,469 张含 $d^+ = 4$ 点）；
2. **紧边界与混合对抗测试**：5 张 $d^+ + \alpha = 6$ 紧边界实例（含 $K_3^* + 6$ 叶、$K_3^* + 3$ 叶 $+ 3$ 汇、$T_5 + 10$ 叶、无双不交准核的 $QR_7 + 7$ 汇、混合 $(4,1)+(4,2)$ 的 $K_4^* + 4$ 叶 $+ 4$ 汇）与 4,995 张多模式混合 $\mathcal{H}$ 图（覆盖全部证明分支与出度高达 11 的 I 型混合图），合计 38,740 张图全部通过 $L^*(v) \ge 1$ 与独立 $2|Q| \le |V|$ 检查；
3. **定向 $(4,3)$ 新反例**：18 点 $G_3$（$g \equiv 0, q = 2$）、19 点 $G_4$（$g = g^+ = L^* \equiv 0, q = 2$）、20 点 $\mathbb{Z}_5$ 对称 $G_5$（$g = g^+ = L^* \equiv 0, q = 2$）与 22 点负值例（4 核点 $g = g^+ = -1, q = 3$）；
4. **无界 $\alpha^+ \le k$ 结论**：$M = 1$ 族 $P_4, P_5, P_6$（20/25/30 点精确公式及引理 C 给出 $|Q| = 1$）、引理 B 一步解决 24 点 $CP_8^* + 16$ 叶图（$|Q| = 2$）、以及 1,200 张无源一般有向图（$d = 2, 3, 4$）上的 $\alpha(D) \le \frac{d-1}{d}n$ 验证。

### 4.2　更新后的下一阶段研究问题

1. **无界出度 $\alpha^+(D) \le 2$（$\vec{K}_{1,3}$-free）的小准核猜想（推进 $\frac{2}{3}n \to \frac{1}{2}n$）**：
   现在定理 4 已给出 $\frac{2}{3}n$，而引理 A/B/C 已覆盖全部已知的局部不等式反例族（$K_m^* + 2m$ 叶、$CP_{2r}^* + 4r$ 叶、$P_r$ 与 $\Phi(H)$）。结合[匹配降度与出度四的小准核](匹配降度与出度四的小准核.md)的匹配框架，对 $\alpha^+(D) \le 2$ 图的正权支集 $T$，每个 $c \in T$ 均向独立集 $I$ 射出两条弧，从而对任意 $w \in N_{D[T]}^+(c)$ 均迫使 $w$ 与 $I$ 相邻；探索在同时对引理 A/B/C 不可约的 $\alpha^+(D) \le 2$ 图上构造半权一步覆盖准核 $f(N^+[K]) \ge f(T)/2$（超越二分核完美划分，例如涵盖 7 点 Paley 竞赛图），或直接推进出度 5 与无界 $\alpha^+ \le 2$。
2. **最大出度 4 下的多项式时间构造**：
   本文定理 2 给出图类 $\mathcal H$ 上的局部算法。[出度四存在性证明](匹配降度与出度四的小准核.md)覆盖全部 $\Delta^+(D)\le4$。后续的[多项式构造证明稿](出度四的多项式构造.md)用分数点覆盖和匹配处理出度四，待独立审读。
3. **定向 $\vec{K}_{1,3}$-free（$\alpha^+ \le 2$）上的无条件局部反例问题**：
   定向 $(4,3)$ 与双向 $(5,2)$ 均已无条件否定 $g^+ \ge 1$，但定向 $\alpha^+ \le 2$ 图上目前仅有条件于 SSNC 的归约函子 $\Phi(H)$。检验是否存在不依赖 SSNC 反例的有限定向 $\vec{K}_{1,3}$-free 图满足全图 $g^+(v) \le 0$（以及是否可绕过 $P_r$ 中的双向边）。
