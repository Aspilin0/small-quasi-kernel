# §1　定理 1 证明：M = 1

[总览和定理陈述](Clow-统一极大局部定理与反例边界.md) · [上一节](Clow-H-核心引理与M0M3.md) · [下一节](Clow-H-M2.md)

#### 情形 $M = 1$

此时对所有 $u \in C$ 有 $c_1^0(u) \le 1$。先建立一条在后续步骤中反复使用的局部排除工具：

**子引理 M1-V（$M = 1$ 的非 I 型虚汇点排除）.** 在 $M = 1$ 下，若 $w \in C$ 满足 $d^+(w) \in \{1, 2, 3, 4\}$ 且存在 $t \in A(w)$ 使 $N^+(t) \cap S(w) = \emptyset$，并满足以下任一附加条件：
* （i）$t \in K$ 为真实汇点，且 $w$ 非 I 型（或 $d^+(w) \le 3$）；或
* （ii）$t \in I_1$（唯一前驱为 $w$），且 $w$ 非 I 型（或 $d^+(w) \le 3$）；

则矛盾。

*证明.* 若 $d^+(w) = 1$ 则 $S(w) = \emptyset$；若 $d^+(w) = 2$（$A(w) = \{t, r_1\}$），则 $F(w) \subseteq A(r_1) \cap (I_1 \cap Z)$ 致 $|F(w)| \le 1 < 2$。下设 $d^+(w) \in \{3, 4\}$，记 $R = A_C(w) \setminus \{t\}$（大小 $d^+(w) - 1$，注意在（ii）下若 $R$ 含汇点 $z \in K$ 则 $z$ 归入（i）已先排除，或直接令 $|R| \le d^+(w) - 1$）。因每个 $s \in F(w)$ 仅从 $R$ 接收弧，有 $f_1(w) \le |R| \le d^+(w) - 1$。若 $B_3(w) \neq \emptyset$，由引理 H3 得 $|X(w)| \ge 4 \implies 2|F(w)| - f_1(w) \ge 2(d^+(w) + 4) - (d^+(w) - 1) = d^+(w) + 9$，而 $\sum_{r \in R} m_r \le 3(d^+(w) - 1) < d^+(w) + 9$（因 $d^+(w) \le 4$），矛盾。故 $m_r \le 2$ 对所有 $r \in R$ 成立，从而
$$d^+(w) + 1 + 2|X(w)| \le 2(d^+(w) + |X(w)|) - (d^+(w) - 1) \le 2|F(w)| - f_1(w) \le \sum_{r \in R} m_r \le 2(d^+(w) - 1).$$
* **$d^+(w) = 3$**（$R = \{r_1, r_2\}$）：上式迫使 $|X(w)| = 0, |F(w)| = 3, f_1(w) = 2, f_{\ge 2}(w) = 1, m_{r_1} = m_{r_2} = 2$。令 $Q_1 = A(r_1) \cap F(w)$（大小 2，独立），有 $N^+(Q_1) \subseteq \{t, r_1, r_2\}$（不含 $w$）。
  * 若 $d^+(r_1) = 4$（$\alpha(r_1) = 2$）：由引理 H1 得 $r_1 \not\to w$ 且 $A(r_1) \setminus Q_1 \subseteq \{t, r_2\}$。在（ii）下 $t \in I_1$ 仅有前驱 $w \neq r_1$，故 $r_1 \not\to t$，得 $|A(r_1) \setminus Q_1| \le 1$ 矛盾；在（i）下 $A(r_1) = Q_1 \cup \{t, r_2\}$，由事实 1 知 $Q_1$ 与汇点 $t$ 均不射入 $S(r_1)$，故 $F(r_1) \subseteq A(r_2) \cap (I_1 \cap Z)$（大小至多 $1 < 4$），矛盾。
  * 若 $d^+(r_1) \le 3$：若 $r_1 \not\to w$，由事实 1 知 $Q_1$ 不射入 $S(r_1)$，致 $|F(r_1)| \le 1 < d^+(r_1)$；若 $r_1 \to w$，则 $A(r_1) = Q_1 \cup \{w\} \implies S(r_1) \subseteq \{t, r_2\}$（大小至多 $2 < 3$），均矛盾。
* **$d^+(w) = 4$**（$R = \{r_1, r_2, r_3\}$）：上式迫使 $5 + 2|X(w)| \le 6 \implies |X(w)| = 0, |F(w)| = 4, f_1(w) \in \{2, 3\}$，且至少两个 $r \in R$ 满足 $m_r = 2$（不妨 $m_{r_1} = 2$）。令 $Q_1 = A(r_1) \cap F(w)$（大小 2，独立），有 $N^+(Q_1) \subseteq \{t, r_1, r_2, r_3\}$（不含 $w$），且 $\alpha(r_1) \ge 2 \implies d^+(r_1) \in \{2, 3, 4\}$。
  * $d^+(r_1) = 2$：$r_1 \not\to w$，由事实 1 得 $S(r_1) = \emptyset$，矛盾。
  * $d^+(r_1) = 3$：若 $r_1 \not\to w$，由事实 1 得 $|F(r_1)| \le 1 < 3$；若 $r_1 \to w$，则 $A(r_1) = Q_1 \cup \{w\} \implies S(r_1) \subseteq \{t, r_2, r_3\}$，而 $f_1(w) \ge 2$ 且 $c_1^0(r_1) \le 1$ 迫使 $r_2, r_3$ 中至少一者有入度 1 子点，从而不在 $Z$ 中、不在 $F(r_1)$ 中，得 $|F(r_1)| \le 2 < 3$，矛盾。
  * $d^+(r_1) = 4$（$\alpha(r_1) = 2$）：由引理 H1 得 $r_1 \not\to w$ 且 $A(r_1) = Q_1 \cup \{x_1, x_2\}$（$x_1, x_2 \in \{t, r_2, r_3\}$）。由事实 1 知 $Q_1$ 不射入 $S(r_1)$。在（ii）下 $r_1 \not\to t$，故 $\{x_1, x_2\} = \{r_2, r_3\}$；在（i）下若 $t \in \{x_1, x_2\}$ 则 $t \in K$ 亦不射入 $S(r_1)$，得 $|F(r_1)| \le 1 < 4$，故同样迫使 $\{x_1, x_2\} = \{r_2, r_3\}$。此时 $F(r_1)$ 全部前驱在 $\{r_2, r_3\}$ 中，有 $f_1(r_1) \le 2$；若 $B_3(r_1) \neq \emptyset$ 则引理 H3 给 $|X(r_1)| \ge 4 \implies 2|F(r_1)| - f_1(r_1) \ge 14 > 6$，矛盾，故 $m_{r_1}(r_2), m_{r_1}(r_3) \le 2$，得 $2|F(r_1)| \le 4 + f_1(r_1) \le 6 \implies |F(r_1)| \le 3 < 4$，矛盾。$\square$

现在按四步收尾 $M = 1$：

1. **全图无汇点（$K = \emptyset$）**：反设存在 $z \in K$，记 $P_z = N^-(z) \subseteq C$。由子引理 M1-V（i）知 $P_z$ 中不含 $d^+(w) \le 3$ 或 II/III 型顶点，故所有 $w \in P_z$ 均为 I 型（$\alpha(w) = 1$）。任取 $w \in P_z$：因 $z \in A(w)$ 无出边且 $\alpha(w) = 1$，每个 $a \in A_C(w)$ 必指向 $z$，即 $A_C(w) \subseteq P_z$，从而每个 $a \in A_C(w)$ 亦为 I 型，有 $m_a \le \alpha(a) = 1$。故 $|F(w)| \le \sum_{a \in A_C(w)} m_a \le |A_C(w)| = d^+(w) - 1 < d^+(w)$，矛盾。
2. **最小出度 $\delta^+(D) \ge 2$**：若 $d^+(v) = 1$（$A(v) = \{a\}$），则 $F(v) \subseteq A(a) \cap (I_1 \cap Z)$ 迫使 $F(v) = \{t\}$（$t \in I_1$）且 $|X(v)| = 0$，即 $N^+(t) \subseteq \{a\}$。考察 $a$：若 $\alpha(a) = 1$，因 $t \in I_1$ 且 $N^+(t) \subseteq \{a\}$ 与 $A(a) \setminus \{t\}$ 间双向无弧，迫使 $A(a) = \{t\} \implies S(a) = \emptyset$ 矛盾；否则 $a$ 非 I 型（或 $d^+(a) \le 3$），直接矛盾于子引理 M1-V（ii）。
3. **全局无 $B_3$ 与满子集障碍**：对任意 $v \in V(D)$，先证 $B_3(v) = \emptyset$。若 $x \in B_3(v)$，由引理 H3（结合 $K = \emptyset, \delta^+ \ge 2$）得 $|X(v)| \ge 5$。若 $d^+(v) \le 4$，则 $2|F(v)| - f_1(v) \ge 2(d^+(v) + 5) - d^+(v) = d^+(v) + 10 > 3d^+(v) \ge \sum m_a$（因 $d^+(v) \le 4$），矛盾；若 $d^+(v) \ge 5$（$\alpha(v) = 1$），因 $f_1(v) \le d^+(v)$ 且 I 型出邻点 $m_a \le 1$，由 $(\ddagger)$ 得 $10 \le 2|X(v)| \le \sum_{a \in W(v)} (m_a - 1) \le 6$，矛盾。故处处 $m_a \le 2$。
   再证对任意 $v$ 及 $a_1 \in A(v)$ 均有 $A(a_1) \not\subseteq F(v)$：因 $m_{a_1} \le 2$ 且 $\delta^+ \ge 2$，只需排除 $d^+(a_1) = 2, A(a_1) \subseteq F(v)$。此时引理 H3 给 $|X(v)| \ge 4$。若 $d^+(v) \le 4$，由 $2(d^+(v) + |X(v)|) - d^+(v) \le 2d^+(v)$ 得 $2|X(v)| \le d^+(v) \le 4 \implies |X(v)| \le 2 < 4$，矛盾；若 $d^+(v) \ge 5$（$\alpha(v) = 1$），令 $W_2 = \{a \in A(v) : m_a = 2\}$（大小 $w_2$），有 $2|X(v)| \le w_2$。但每个 $a \in W_2$ 满足 $d^+(a) \le 4$ 且送 2 条弧入 $F(v)$，故 $d_{D[W_2]}^+(a) \le 2$；又 $a_1 \in W_2$ 满足 $d_{D[W_2]}^+(a_1) = 0$，由 $D[W_2]$ 半完全知所有 $a \in W_2 \setminus \{a_1\}$ 均指向 $a_1$，从而在半完全图 $D[W_2 \setminus \{a_1\}]$ 内出度至多 1，得 $\binom{w_2 - 1}{2} \le w_2 - 1 \implies w_2 \le 4$，于是 $2|X(v)| \le 4 \implies |X(v)| \le 2 < 4$，矛盾。
4. **按最小出度 $\delta = \min_v d^+(v)$ 排除**：
   * **$\delta = 2$**：取 $d^+(v) = 2$（$A(v) = \{a_1, a_2\}$），记 $t_j = |\{s \in F(v) : d^-(s) = j\}|$。因 $m_{a_1}, m_{a_2} \le 2$ 且 $t_1 \le 2$，有 $t_1 + 2t_2 \le 4$ 与 $t_1 + t_2 \ge 2 + |X(v)|$：
     * $(t_1, t_2) = (2, 0)$：$|X(v)| = 0, F(v) = \{s_1, s_2\} \subseteq I_1$（$a_i \to s_i$），$N^+(s_1) = N^+(s_2) = \{a_1, a_2\}$。若 $a_1 \not\to v$，由事实 1 知 $N^+(s_1) \cap S(a_1) = \emptyset$：若 $\alpha(a_1) = 1$ 则 $A(a_1) \setminus \{s_1\} \subseteq N^+(s_1) \setminus \{a_1\} = \{a_2\} \implies A(a_1) = \{s_1, a_2\} \implies |F(a_1)| \le 1 < 2$；否则直接矛盾于子引理 M1-V（ii）。若 $a_1 \to v$，因 $\{s_1, v\}$ 独立故 $\alpha(a_1) \ge 2 \implies d^+(a_1) \in \{2, 3, 4\}$：$d^+(a_1) \le 3$ 同[Clow-5.1-证明](Clow-5.1-证明.md)矛盾；若 $d^+(a_1) = 4$（$A(a_1) = \{s_1, v, r_1, r_2\}$），由 $N^+(s_1) = N^+(v) = \{a_1, a_2\}$ 及 $a_2$ 有入度 1 子点 $s_2 \implies a_2 \notin Z \implies F(a_1) \cap \{a_1, a_2\} = \emptyset$，知 $s_1, v$ 均不射入 $F(a_1)$，故 $F(a_1)$ 全由 $\{r_1, r_2\}$ 供给，由 $m_{a_1}(r_i) \le 2$ 与 $f_1(a_1) \le 2$ 得 $2|F(a_1)| \le 4 + 2 = 6 \implies |F(a_1)| \le 3 < 4$，矛盾。
     * $(t_1, t_2) \in \{(1, 1), (0, 2)\}$：$|X(v)| = 0$，$Q := F(v) \subseteq A(a_1)$（大小 2，独立），$N^+(Q) = \{a_1, a_2\}$。若 $d^+(a_1) = 4$（$\alpha(a_1) = 2$），引理 H1 得 $A(a_1) \setminus Q \subseteq \{a_2\}$（大小至多 1）矛盾；$d^+(a_1) \le 3$ 同[Clow-5.1-证明](Clow-5.1-证明.md)矛盾。
     * $(t_1, t_2) = (2, 1)$：$|F(v)| = 3, |X(v)| \le 1, m_{a_1} = m_{a_2} = 2$，$Q_1 = A(a_1) \cap F(v) = \{s_1, p\}$。因 $A(a_1) \not\subseteq F(v)$ 故 $d^+(a_1) \in \{3, 4\}$。$d^+(a_1) = 3$ 同[Clow-5.1-证明](Clow-5.1-证明.md)矛盾；若 $d^+(a_1) = 4$（$\alpha(a_1) = 2$），引理 H1 给出：若 $a_1 \not\to v$，则 $|X(v)| = 1$（记 $X(v) = \{x\}$）且 $A(a_1) = Q_1 \cup \{a_2, x\}$，由事实 1 知 $Q_1$ 不射入 $S(a_1)$，故 $2|F(a_1)| \le 4 + f_1(a_1) \le 6 \implies |F(a_1)| \le 3 < 4$；若 $a_1 \to v$，则 $X(v) = \{v\}$ 且 $A(a_1) = Q_1 \cup \{a_2, v\}$，此时 $Q_1$ 与 $v$ 的出邻集均含于 $N^+[a_1]$，故 $F(a_1) \subseteq A(a_2) \cap (I_1 \cap Z)$ 致 $|F(a_1)| \le 1 < 4$，均矛盾。
   * **$\delta \ge 5$**：全图均为 I 型（$\alpha^+(D) = 1$），由[禁出星图笔记](Clow-禁出星图与相图.md)定理 1 矛盾。
   * **$\delta \in \{3, 4\}$**：先证对所有满足 $d^+(v) = \delta$ 的点均有 $|X(v)| = 0$。反设某点 $v$ 满足 $d^+(v) = \delta$ 且 $|X(v)| \ge 1$。由 $(\dagger)$（$k = 0, B_3 = \emptyset, f_1(v) \le \delta$）得 $2|X(v)| \le f_1(v) \le \delta$，故 $\delta = 3$ 时 $|X(v)| = 1$、$\delta = 4$ 时 $|X(v)| \in \{1, 2\}$，且在所有情形均有至少两个 $a \in A(v)$ 满足 $m_a = 2$（事实上，$|X(v)| = 2$ 时迫使 $\delta = 4, f_1(v) = 4, |F(v)| = 6$ 且全部 4 个 $a \in A(v)$ 均有 $m_a = 2$；$|X(v)| = 1$ 时由 $\sum (2 - m_a) \le f_1(v) - 2 \le \delta - 2$ 得至少两个 $a \in A(v)$ 满足 $m_a = 2$）。任取 $a_1 \in A(v)$ 使 $m_{a_1} = 2$，记 $Q_1 = A(a_1) \cap F(v)$（大小 2，独立），则 $\alpha(a_1) \ge 2 \implies d^+(a_1) \in \{\delta, 4\}$。
     * 若 $d^+(a_1) = 3$（此时 $\delta = 3, |X(v)| = 1$）：同[Clow-5.1-证明](Clow-5.1-证明.md)情形 $M = 1$ 步骤 5 矛盾（$a_1 \not\to v$ 时 $|F(a_1)| \le 1 + 1 = 2 < 3$；$a_1 \to v$ 时迫使 $A(a_2) = A(a_3) = A(a_1)$ 致 $|F(v)| \le 2 < 4$）。
     * 若 $d^+(a_1) = 4$（$\alpha(a_1) = 2$）：由引理 H1，记 $A(a_1) = Q_1 \cup \{y_1, y_2\}$：
       * 当 $a_1 \not\to v$ 时，$\{y_1, y_2\} \subseteq (A(v) \setminus \{a_1\}) \cup X(v)$。由事实 1 知 $S(a_1) \cap A(v) = \emptyset$，故 $Q_1$ 仅能在 $R_X := X(v) \setminus \{y_1, y_2\}$ 中射入 $S(a_1)$；又 $Q_1 \subseteq Z \implies f_1(a_1) \le c_1^0(y_1) + c_1^0(y_2) \le 2$。记 $t = |F(a_1) \cap R_X| \in \{0, 1, 2\}$，$F' = F(a_1) \setminus R_X$，则 $F'$ 全部弧来自 $\{y_1, y_2\}$（至多 4 条），有 $2|F'| - 2 \le 4 \implies |F'| \le 3$。因 $|F'| = |F(a_1)| - t \ge 4 + |X(a_1)| - t$：若 $t = 0$ 则 $|F'| \ge 4$ 矛盾；若 $t \ge 1$，则 $|X(a_1)| \le t - 1$（具体地：$t = 1$ 时 $|X(a_1)| = 0$，$t = 2$ 时 $|X(a_1)| \le 1$ 且必有 $|X(v)| = 2 \implies \delta = 4$）。任取 $x \in F(a_1) \cap R_X \subseteq X(v)$：因 $Q_1 \subseteq S(v)$ 的全部前驱在 $A(v)$ 中而 $X(v) \cap A(v) = \emptyset$，有 $x \not\to Q_1$，故 $N^+(x) \subseteq \{y_1, y_2\} \cup X(a_1)$，大小至多 $2 + |X(a_1)| \le \delta - 1 < \delta$，矛盾！
       * 当 $a_1 \to v$ 时，由引理 H1 得 $v \in X(v)$，且 $y_1 = v$（不妨），$y_2 \in (A(v) \setminus \{a_1\}) \cup (X(v) \setminus \{v\})$。若 $|X(v)| = 1$，则 $X(v) = \{v\}$，$Q_1$ 与 $v$ 仅指向 $A(v) \cup \{v\}$，故 $F(a_1) \setminus A(v) \subseteq A(y_2) \cap (I_1 \cap Z)$（大小至多 1），而 $A(v) \setminus \{a_1, y_2\}$ 大小至多 $\delta - 2 \le 2$，得 $|F(a_1)| \le 2 + 1 = 3 < 4$，矛盾；若 $|X(v)| = 2$（此时 $\delta = 4, f_1(v) = 4$），则每个 $a_j \in A(v)$ 均有入度 1 子点，从而 $A(v) \cap Z = \emptyset \implies F(a_1) \cap A(v) = \emptyset$！于是 $F(a_1) \subseteq (X(v) \setminus \{v\}) \cup (A(y_2) \cap (I_1 \cap Z))$ 大小至多 $1 + 1 = 2 < 4$，矛盾。

   因此所有出度等于 $\delta$ 的顶点均满足 $|X(v)| = 0$，且对任意 $s \in F(v)$ 由 $d^+(s) \ge \delta = |A(v)|$ 得 $N^+(s) = A(v)$（$s \not\to v$）。
   * 若 $\delta = 4$：先证对任意 $d^+(v) = 4$ 均有 $m_a \le 1$（$\forall a \in A(v)$）：若某 $a_1 \in A(v)$ 有 $m_{a_1} = 2$（$Q_1 = A(a_1) \cap F(v)$），则 $d^+(a_1) = 4, \alpha(a_1) = 2$，由引理 H1 得 $a_1 \not\to v$ 且 $A(a_1) = Q_1 \cup \{y_1, y_2\}$（$y_1, y_2 \in A(v)$），由事实 1 知 $Q_1$ 不射入 $S(a_1)$，得 $2|F(a_1)| \le 4 + f_1(a_1) \le 6 \implies |F(a_1)| \le 3 < 4$，矛盾。从而每个 $d^+(v) = 4$ 的顶点均满足 $F(v) = \{s_1, s_2, s_3, s_4\} \subseteq I_1$（$a_i \to s_i$）与 $N^+(s_i) = A(v)$。任取 $a_1 \in A(v)$：若 $a_1 \not\to v$，则 $s_1 \in A(a_1) \cap I_1$ 不射入 $S(a_1)$；若 $\alpha(a_1) = 1$ 则 $A(a_1) \setminus \{s_1\} \subseteq N^+(s_1) \setminus \{a_1\} = \{a_2, a_3, a_4\}$ 仍迫使 $d^+(a_1) = 4$；无论哪种情形均有 $d^+(a_1) = 4$，故 $m_{a_1}(x) \le 1$ 对所有 $x \in A(a_1)$ 成立且 $m_{a_1}(s_1) = 0$，得 $|F(a_1)| \le 3 < 4$，矛盾。若 $a_1 \to v$，则 $\{s_1, v\}$ 独立迫使 $d^+(a_1) = 4$（$A(a_1) = \{s_1, v, y_1, y_2\}$），又因每个 $a_j \in A(v)$ 均有入度 1 子点 $s_j$，故 $A(v) \cap Z = \emptyset \implies F(a_1) \cap A(v) = \emptyset$，于是 $s_1, v$ 均不射入 $F(a_1)$，得 $2|F(a_1)| \le 4 + f_1(a_1) \le 6 \implies |F(a_1)| \le 3 < 4$，矛盾。
   * 若 $\delta = 3$：任取 $d^+(v) = 3$（$|X(v)| = 0$）。若某 $a_1 \in A(v)$ 满足 $m_{a_1} = 2$（$Q_1 = A(a_1) \cap F(v)$），则 $d^+(a_1) \in \{3, 4\}$：若 $d^+(a_1) = 4$（$\alpha(a_1) = 2$），引理 H1 得 $a_1 \not\to v$ 且 $A(a_1) = Q_1 \cup \{a_2, a_3\}$，由事实 1 知 $Q_1$ 不射入 $S(a_1)$，致 $|F(a_1)| \le 3 < 4$ 矛盾；故 $d^+(a_1) = 3$ 且 $|X(a_1)| = 0$，取 $t \in Q_1 \subseteq F(v)$，由每个 $a' \in F(a_1)$ 满足 $d^+(a') \ge 3 = |A(a_1)|$ 得 $A(a') = A(a_1) \ni t$，于是 $\{a_1\} \cup F(a_1) \subseteq N^-(t) \subseteq A(v)$，得 $4 \le 3$ 矛盾。因此所有 $a \in A(v)$ 均满足 $m_a = 1$，即 $F(v) = \{s_1, s_2, s_3\} \subseteq I_1$（$a_i \to s_i$）与 $N^+(s_i) = A(v)$。若任一 $a_i$ 有 $d^+(a_i) = 3$（从而 $|X(a_i)| = 0$），同前对 $(v, s_i, a_i)$ 得 $\{a_i\} \cup F(a_i) \subseteq N^-(s_i) \subseteq A(v)$（$4 \le 3$ 矛盾）；故所有 $a_i \in A(v)$ 均有 $d^+(a_i) \ge 4$。考察 $a_1$：若 $a_1 \not\to v$，则 $s_1 \in A(a_1) \cap I_1$ 不射入 $S(a_1)$；若 $\alpha(a_1) = 1$ 则 $A(a_1) \setminus \{s_1\} \subseteq \{a_2, a_3\}$ 致 $d^+(a_1) \le 3$ 矛盾，否则 $d^+(a_1) = 4, \alpha(a_1) = 2$，矛盾于子引理 M1-V（ii）。若 $a_1 \to v$，则 $\{s_1, v\}$ 独立迫使 $d^+(a_1) = 4$（$A(a_1) = \{s_1, v, y_1, y_2\}$），由 $A(v) \cap Z = \emptyset$ 知 $s_1, v$ 均不射入 $F(a_1)$，得 $2|F(a_1)| \le 4 + f_1(a_1) \le 6 \implies |F(a_1)| \le 3 < 4$，矛盾。

至此情形 $M = 1$ 全部排除。
