## 3　$(\Delta^+, \alpha^+)$ 局部不等式的完整负面边界与 SSNC 归约

本节给出多族显式紧反例，精确刻画局部不等式 $L^*(v) \ge 1$、$g(v) \ge 1$ 与 $g^+(v) \ge 1$ 在 $(\Delta^+, \alpha^+)$ 参数平面上的失效边界。

### 3.1　边界反例汇总表

| 参数 $(\Delta^+, \alpha^+)$ | 图类要求 | 最小反例与点数 | 局部指标表现 | 小准核情况 |
| :--- | :--- | :--- | :--- | :--- |
| $(4, 4)$ | 定向图 | Clow 24 点图（8 核 + 16 私有汇点） | 全图 $g = g^+ = L^* = 0$ | 满足 $2\|Q\| \le \|V\|$ |
| $(4, 3)$ | 含双向边 | **$K_3^* + 6$ 私有汇点（9 点）** | 全图 $g = g^+ = L^* = 0$ | $\|Q\| = 3 \le 9/2$ |
| $(4, 3)$ | 定向图 | **$T_5 + 10$ 私有汇点（15 点）** | 全图 $L^* = 0$；核点 $g = 3$ | $\|Q\| = 5 \le 15/2$ |
| $(5, 3)$ | 定向图（$\vec{K}_{1,4}$-free） | **$QR_7 + 14$ 私有汇点（21 点）** | 核点 $g = g^+ = -1$，汇点 $0$ | $\|Q\| = 7 \le 21/2$ |
| $(\frac{p+3}{2}, 3)$ | 定向图（$\vec{K}_{1,4}$-free） | $QR_p + 2p$ 私有汇点（$p \equiv 3 \bmod 4$） | 核点 $g = g^+ = 2 - \frac{p-1}{2} \to -\infty$ | 满足 $2\|Q\| \le \|V\|$ |
| $(5, 2)$ | 含双向边 | **$K_4^* + 8$ 叶（12 点）** | 核 $g=0, g^+=1$；叶 $g=g^+=-2$；全图 $L^* \le 0$ | 引理 A 一步归约，$\|Q\|=2$ |
| $(6, 2)$ | 含双向边 | **$K_5^* + 10$ 叶（15 点）** | 核 $g=-1, g^+=0$；叶 $g=g^+=-3$ | 引理 A 一步归约，$\|Q\|=2$ |
| $(7, 2)$ | 含双向边 | **$K_6^* + 12$ 叶（18 点）** | 核 $g=-2, g^+=-1$；叶 $g=g^+=-4$ | 引理 A 一步归约，$\|Q\|=2$ |
| $(8, 2)$ | 含双向边且**引理 A 不可约** | **鸡尾酒会核 $CP_8^* + 16$ 叶（24 点）** | 全图 $g \le -2, g^+ \le -1$ | 满足 $2\|Q\| \le \|V\|$ |

其中关键构造说明如下：
* **Paley 汇点族 $QR_p + 2p$ 私有汇点（否定定向 $\vec{K}_{1,4}$-free 上的 $g^+ \ge 1$）**：取 $p \equiv 3 \pmod 4$（$p \ge 7$）的 Paley 竞赛图 $QR_p$（出度 $k = \frac{p-1}{2}$），每点挂载 2 个私有汇点。因 $QR_p$ 中每点的出邻集是竞赛图（$\alpha = 1$），总 $\alpha^+ = 1 + 2 = 3$；删去 $N^+[u]$ 后余下的 $k$ 个核点诱导正则或无源子竞赛图（$p=7$ 时为有向 3-环），故 $S(u)$ 恰为被删 $k$ 个核点的 $2k$ 个私有汇点，$|E(u)| = k + 2$，$g^+(u) = g(u) = 2 - k$（$p=7$ 时为 $-1$）。
* **定向 $(4, 3)$ 的三角形同调阻碍（$T_5 + 10$ 汇点）**：正则 5-竞赛图每点挂 2 个私有汇点，满足 $\Delta^+ = 4, \alpha^+ = 3$。删去 $N^+[i]$ 后 $S(i) = \{i+3\} \cup \{\text{4 汇点}\}$：取子集 $F$ 只留 4 个汇点即得 $L^*(i) = 4 - 4 = 0$；但在任意保持三角形（从而保持 $\alpha^+ \le 3$）的有限覆盖中，两条路 $i \to i+1 \to i+3$ 与 $i \to i+2 \to i+3$ 跨过两个有向三角形 $(i, i+1, i+2)$ 与 $(i+1, i+2, i+3)$ 同调，必抵达同一副本，故无法在保持 $\alpha^+ \le 3$ 的前提下通过覆盖消去核心新源 $i+3$。
* **双向团加双叶族 $K_m^* + 2m$ 叶与引理 A 不可约的 $CP_{2r}^* + 4r$ 叶**：
  * 在完全双向图 $K_m^*$（$m \ge 4$）上，给每点 $i$ 添两个入度为 1 的单向子点 $y_{i,1}, y_{i,2}$，令 $N^+(y_{i,1}) = N^+(y_{i,2}) = C \setminus \{i\}$。则 $\alpha^+(D) = 2$，核点 $g(i) = (m+2) - 2(m-1) = 4 - m$，$g^+(i) = 5 - m$；叶点 $g(y) = g^+(y) = m - 2(m-1) = 2 - m$。
  * 将核心换为删去完美匹配的双向鸡尾酒会图 $CP_{2r}^*$（$m = 2r \ge 8$，每点 $i$ 不连配对点 $i \oplus 1$），仍令 $N^+(y_{i,b}) = C \setminus \{i\}$（含 $i \oplus 1 \notin N^+[i]$）。此时仍保持 $\alpha^+(D) = 2$，**引理 A 完全不可约**，但核点 $g(i) = (2r+2) - 2(2r-2) = 6 - 2r \le -2, g^+(i) = 7 - 2r \le -1$，叶点 $g(y) = 2r - 2(2r-1) = 2 - 2r \le -6$。

### 3.2　定向 $\vec{K}_{1,3}$-free 图与 Seymour 第二邻域猜想的精确归约

**定理 3（SSNC 归约函子）.** 对任意有限非空无源定向出竞赛图 $H$（无双向边且 $\alpha^+(H) \le 1$），构造有向图 $\Phi(H)$ 如下：
1. 核心 $C = H[QR_7]$ 为 $H$ 与 7 点 Paley 竞赛图的字典序积（共 $7|V(H)|$ 个核点 $(i, c)$）；
2. 对每个核点 $u = (i, c) \in C$，添加两个入度为 1 的私有点 $y_{u,1}, y_{u,2}$，连弧 $u \to y_{u,1}, u \to y_{u,2}$，并令 $N^+(y_{u,1}) = N^+(y_{u,2}) = N_C^+(u)$。

则 $\Phi(H)$ 是有限无源无汇**定向 $\vec{K}_{1,3}$-free 图**（无双向边，$\alpha^+(\Phi(H)) = 2$，共 $21|V(H)|$ 个顶点），且对每个 $i \in V(H), c \in \mathbb{Z}_7, b \in \{1, 2\}$ 精确成立：
$$g_{\Phi(H)}(i, c) = g^+_{\Phi(H)}(i, c) = 2 + 7\Bigl(\bigl|N_H^{++}(i) \setminus N_H^+(i)\bigr| - d_H^+(i)\Bigr),$$
$$g_{\Phi(H)}(y_{(i,c), b}) = g^+_{\Phi(H)}(y_{(i,c), b}) = 7\Bigl(\bigl|N_H^{++}(i) \setminus N_H^+(i)\bigr| - d_H^+(i)\Bigr).$$

*证明.* 因 $H$ 无双向边且 $\alpha^+(H) \le 1$，对每个 $u = (i, c)$，$N_C^+(u) = N_{QR_7}^+(c) \sqcup \bigcup_{j \in N_H^+(i)} B_j$ 诱导竞赛图（$\alpha = 1$）；又 $y_{u,1}, y_{u,2}$ 指向整个 $N_C^+(u)$，故 $\alpha(\Phi(H)[N^+(u)]) = 2$，$\alpha(\Phi(H)[N^+(y_{u,b})]) = 1$，且无双向边。删去 $N^+[u]$ 后，未删簇中的 $QR_7$ 内部保持每个顶点至少有 3 个存活前驱，$B_i$ 中余下的 3 点由 $H$ 中 $i$ 的入邻簇指向，故 $S(u)$ 恰为 $N_C^+(u)$（大小 $3 + 7d_H^+(i)$）的全部 $6 + 14d_H^+(i)$ 个叶点；而 $E(u) = \{y_{u,1}, y_{u,2}\} \cup (B_i \setminus \{(i,c)\}) \cup \bigcup_{k \in N_H^+(i) \cup N_H^{++}(i)} B_k$（因 $H$ 无双向边，$i \notin N_H^{++}(i)$），大小为 $2 + 6 + 7d_H^+(i) + 7|N_H^{++}(i) \setminus N_H^+(i)|$，相减即得核点公式，且 $(i,c) \notin E(u) \implies g^+ = g$。叶点 $y_{u,b}$ 的闭出邻集仅少删 $(i,c)$ 与 $y_{u, 3-b}$（均仍保有存活前驱），$S$ 不变而 $E$ 少 $\{y_{u,1}, y_{u,2}\}$ 两点，相减即得叶点公式。$\blacksquare$

**推论.** 若存在定向出竞赛图 $H$ 违反 Seymour 第二邻域猜想（即对所有 $i \in V(H)$ 均有 $|N_H^{++}(i) \setminus N_H^+(i)| \le d_H^+(i) - 1$），则 $\Phi(H)$ 是满足**全图 $g^+(v) = g(v) \le -5$** 的定向 $\vec{K}_{1,3}$-free 图。因此，在无界出度的定向 $\vec{K}_{1,3}$-free 图上直接证明 Clow 局部不等式 $g(v) \ge 1$，难度至少不低于解决定向出竞赛图上的 Seymour 第二邻域猜想；而使用第 1.2 节的**引理 A** 则可一步消去 $\Phi(H)$ 的全部叶点，完全绕开第二邻域问题。

### 4.2　交接清单（推荐推进优先级）

以下保留本轮结束时的研究问题。后续的[边界实例验证器](../experiments/clow-classH-verify.mjs)给出了 19 点定向图，反驳第 3 项中的局部猜测，也构造了第 2 项中 $M=1$ 的障碍。[项目首页](../README.md)列出当前主线。

1. **优先级 1（近在咫尺的统一局部定理：合龙遗传图类 $\mathcal{H}$）**
   第 3.1 节的全部双向边反例恰好落在逐点条件
   $$\mathcal{H}: \quad \forall u \in V(D),\quad \alpha\bigl(D[N^+(u)]\bigr) \le 1 \;\;\text{或}\;\; d^+(u) + \alpha\bigl(D[N^+(u)]\bigr) \le 6$$
   的紧外侧（$(4,4), (4,3), (5,2)$ 均满足 $d^+ + \alpha^+ \ge 7$），而 $\mathcal{H}$ 对导出子图严格遗传，且模拟退火与混合随机测试均保持 $\max_{v \in C} L^*(v) \ge 1$。
   * **已有拼图**：$d^+ \le 3$ 已由 [Clow-5.1-证明](Clow-5.1-证明.md) 解决；$\alpha^+ \le 1$（任意出度）已由本文定理 1 解决；$\alpha^+ \le 2$ 的 $M = 0$ 情形已由本文定理 2 解决。
   * **剩余唯一缺口**：在全图满足 $\mathcal{H}$ 的前提下，补齐存在 $(d^+(u), \alpha(D[N^+(u)])) = (4, 2)$ 顶点且 $M \in \{1, 2\}$ 时的有限分支排除（利用主恒等式 $(\star)$ 与引理 1.2 的 2-扇出刚性，此时 $d^+(u) \le 4$ 使外溢与回指弧数完全受控）。一旦合龙，即可一举得到涵盖全体 $\Delta^+ \le 3$ 图、全体局部出半完全图（$\alpha^+ \le 1$）与全体 $\Delta^+ \le 4$ 禁出爪图（$\alpha^+ \le 2$）的**精确极大局部定理**。

2. **优先级 2（攻克无界出度 $\vec{K}_{1,3}$-free 图的小准核猜想：双生子点捆绑约简）**
   第 3 节表明无界出度 $\alpha^+(D) \le 2$ 图上阻碍 $g^+(v) \ge 1$ 的唯一根源是 $M = 2$（同一父点 $u$ 带两个入度 1 子点 $y_1, y_2$，如 $CP_8^* + 16$ 叶与 $\Phi(H)$）。下一棒应绕开 $g(v) \ge 1$，直接分析：
   * **路线 2A（双准核互补）**：任取准核 $Q_1$，若 $|Q_1| > n/2$，则 $B = V \setminus Q_1$ 满足 $|B| < n/2$，且每个 $b \in B$ 至多向 $Q_1$ 送出 $\alpha(D[N^+(b)]) \le 2$ 条弧；结合 2-扇出刚性限制 $D[B]$ 与 $Q_1$ 间的双向结构，在 $B \cup Q_1$ 中重配出 $\le n/2$ 的准核。
   * **路线 2B（升级版局部删除）**：当 $u$ 带两个入度 1 子点 $y_1, y_2$ 时，由 $\alpha(D[N^+(u)]) \le 2$ 知 $N^+(u) \setminus \{y_1, y_2\} \subseteq N^+(y_1) \cup N^+(y_2)$，研究同时删除 $\{u\} \cup N^+(u) \cup N^+(y_1) \cup N^+(y_2)$ 并按 $u$ 是否被外部覆盖在 $\{u\}$ 与 $\{y_1, y_2\}$ 间切换选点的归纳步。

3. **优先级 3（定向 $(4, 3)$ 图的原图不等式 $g^+(v) \ge 1$）**
   在无双向边、$\Delta^+(D) \le 4$ 且 $\vec{K}_{1,4}$-free 的定向图上，$T_5 + 10$ 汇点虽令 $L^* \equiv 0$，但因三角形同调阻碍仍满足 $\max_v g(v) = 3 \ge 1$。下一棒可检验该类定向图在原图上是否恒有 $\max_v g^+(v) \ge 1$（从而将小准核定理推进至全体最大出度 $\le 4$ 的 $\vec{K}_{1,4}$-free 定向图）。
